# Project Statement

## Project Name

Library Management System

## Problem Statement

Managing books manually can be difficult when there are many books in a library. It can take time to check which books are available and which books have been borrowed.

This project is made to provide a simple way to manage basic library activities using Python.

## Objective

The main objective of this project is to create a simple program that can:

* Add books to the library
* Display available books
* Borrow books
* Return borrowed books
* Keep track of available and borrowed books

## Proposed Solution

The program uses Python lists to keep track of the books. One list stores the books available in the library, while another list stores the borrowed books.

A simple menu is provided so that the user can select the required operation.

## Scope

This project is mainly designed for learning and understanding basic Python programming. It can later be improved by adding features like a database, user login, search option, due dates, and fine calculation.

## Conclusion

The Library Management System is a basic project that makes simple book management easier. It also helped me understand how Python functions, lists, loops, and c
