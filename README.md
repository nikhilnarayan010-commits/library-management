# Library Management System

## About the Project

This is a simple Library Management System made using Python. It is a console-based project where users can add books, see available books, borrow books, and return them.

## Features

* Add a new book
* Show available books
* Borrow a book
* Return a book
* Exit the program

## Technologies Used

* Python
* Lists
* Functions
* Loops
* If-else statements

## How to Run

Make sure Python is installed on your computer. Then run the Python file:

```bash
python "LIBRARY MANAGEMENT SYSTEM.py"
```

After running it, choose an option from the menu and follow the instructions.

## Working

The program keeps available books in one list and borrowed books in another list. When a book is borrowed, it moves to the borrowed list. When it is returned, it is added back to the available books.

## Conclusion

This project helped me understand the basics of Python, especially functions, lists, loops, and conditional statements. It is a basic version of a library system that can be improved with more features in the future.
